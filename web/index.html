Method, validation & caveats

All numbers below are generated from the local NASA FIRMS archive by firms_pipeline.py.

—

What is harmonised here?

Raw monthly hotspot counts are put on the VIIRS S-NPP reference scale with a scalar multiplicative factor fitted on 2013–2022 and tested on 2023–2025. The factor is not a burned-area conversion and does not turn a detection into a confirmed fire incident.

A whole-year leave-one-out check (14 folds over 2012–2025) keeps counts as the primary metric: raw MAE drops ~62% (Terra) and ~56% (Aqua), outperforming cell-day scaling in September–October too.

Why the caveats are visible

MODIS Collection 6.x versions change over time (6.2 → 6.03 → 61.03), so values before 2013 are labelled extrapolated.

NOAA-20 did not pass the held-out count test (MAE worsened), so raw values are kept explicitly. When a mixed MODIS/S-NPP baseline flips the anomaly sign, both medians are surfaced.

How to read a cell

Observed
S-NPP reference count (factor 1.0).
Calibrated
Estimate inside validated 2013–2025 window.
Extrapolated
Pre-2013 estimate; interpret with caution.
Raw only
Not harmonised (custom box or failed test).
Partial
Archive covers only part of the month.
Missing
No local input; no value is invented.
Primary calibration (hotspot counts)

Training and test months are separate. Bias is adjusted minus reference. A negative raw bias means MODIS undercounts relative to S-NPP.
